## About Me

안녕하세요! 저는 Crem2y(크렘티)입니다.

임베디드 시스템을 중심으로 펌웨어 개발을 하고 있으며, 필요한 경우 직접 하드웨어를 설계하며 프로젝트를 개발하고 있습니다.

로우레벨 프로그래밍, 커스텀 프로토콜, MCU 기반 시스템 설계에 관심이 많습니다.
